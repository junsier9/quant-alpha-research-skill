# Code of Conduct

This project is a small technical library, but the same baseline applies:
contributors should be respectful, concrete, and evidence-oriented.

## Expected Behavior

- Focus critique on the work, not the person.
- Preserve private project names, credentials, paths, and research artifacts.
- Report validation results honestly, including negative or fail-closed outcomes.
- Avoid publishing hand-authored examples as measured evidence.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Posting secrets, private data, or machine-local identifiers.
- Misrepresenting illustrative eval fixtures as recorded validation runs.

## Reporting

Open a private maintainer channel or security advisory when the issue involves
secrets, private research artifacts, or personal information. Public issues are
appropriate for ordinary bugs, docs gaps, and validation failures.
